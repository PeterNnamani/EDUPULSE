## How To Get Started

### Step 1: Database Migration
```bash
supabase migration up 008_academic_session_management_engine.sql
```

### Step 2: Configure School
```typescript
// Create promotion rules
await promotionEngine.createPromotionRule(...);

// Create fee structures
await feeAutomationService.createFeeStructure(...);
```

### Step 3: Use Dashboard
```typescript
<AcademicSessionDashboard schoolId={schoolId} />
```

### Step 4: Create Session
```typescript
await sessionManagementService.createSession(...);
await sessionManagementService.createDefaultTerms(...);
await sessionManagementService.activateSession(...);
```

### Step 5: Activate Terms
```typescript
await termAutomationService.activateTermWithAutomation(...);
// Everything else is automatic!
```

### Step 6: End-of-Year
```typescript
await sessionRolloverService.executeSessionRollover(...);
// Complete transition with one call!
```
